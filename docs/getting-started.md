# Getting Started with Microsoft Word

Welcome to Microsoft Word. This guide walks you through system requirements, creating your first document, mastering the interface, and applying fundamental styling in under 10 minutes.

---

## Prerequisites & Installation

To run Microsoft Word, ensure your device meets the following specifications:

| Platform | Minimum OS Version | Recommended RAM | Storage |
| :--- | :--- | :--- | :--- |
| **Windows** | Windows 10 (Build 19041+) / Windows 11 | 4 GB (8 GB recommended) | 4.0 GB free space |
| **macOS** | Three most recent macOS releases (Sonoma, Ventura, Monterey) | 4 GB | 10 GB free space |
| **Web Browser** | Edge, Chrome, Safari, Firefox | 2 GB | None (Cloud-hosted) |

### Installing via Microsoft 365

1. Visit [portal.office.com](https://portal.office.com) and sign in with your Microsoft account.
2. In the upper-right corner, click **Install Apps** > **Microsoft 365 apps**.
3. Run the downloaded installer (`OfficeSetup.exe` on Windows or `Microsoft_Office_Installer.pkg` on macOS).
4. Launch Word from your application menu and activate it using your Microsoft account credentials.

---

## Creating Your First Document

When launching Word, the **Start Screen** appears:

1. **Blank Document**: Starts an empty document using the default `Normal.dotm` template (Calibri or Aptos font, 1-inch margins).
2. **Template Gallery**: Choose pre-formatted designs for resumes, invoices, academic research papers, brochures, and meeting minutes.
3. Select **Blank Document** to open a new authoring canvas.

## Core Authoring Workflow

### 1. Typing & Basic Text Formatting
Highlight any word, phrase, or paragraph to format:
- **Bold**: `Ctrl + B` (Windows) or `Cmd + B` (macOS)
- **Italics**: `Ctrl + I` (Windows) or `Cmd + I` (macOS)
- **Underline**: `Ctrl + U` (Windows) or `Cmd + U` (macOS)

### 2. Applying Structural Headings
Do not manually resize and bold text to create headings. Instead, use the **Styles** gallery on the **Home** tab:
1. Place your cursor inside the line intended as a heading.
2. In the **Home** ribbon tab, click **Heading 1** for top-level topics, or **Heading 2** for subtopics.
3. *Why use Styles?* Styles enable automatic navigation via the Navigation Pane (`Ctrl + F`) and allow 1-click Table of Contents generation.

### 3. Inserting Visuals and Media
- **Insert an Image**: Go to **Insert** > **Pictures** > **This Device** or **Stock Images**. Use the *Layout Options* anchor button next to the image to specify text wrapping (e.g., *Square*, *Tight*, *In Line with Text*).
- **Insert a Table**: Go to **Insert** > **Table** > drag to select grid dimensions (e.g., 4 columns by 5 rows).

### 4. Saving Your Work
- **Cloud Storage (Recommended)**: Toggle **AutoSave** in the top-left title bar. Word saves modifications continuously to your OneDrive or SharePoint account every few seconds.
- **Local Disk**: Press `Ctrl + S` (or `F12` for *Save As*), choose a local directory, and save as `.docx`.

## Essential Keyboard Shortcuts

| Action | Windows Shortcut | macOS Shortcut |
| :--- | :--- | :--- |
| **New Document** | `Ctrl + N` | `Cmd + N` |
| **Open Document** | `Ctrl + O` | `Cmd + O` |
| **Save / AutoSave** | `Ctrl + S` | `Cmd + S` |
| **Undo last change** | `Ctrl + Z` | `Cmd + Z` |
| **Redo last change** | `Ctrl + Y` | `Cmd + Y` |
| **Find & Replace** | `Ctrl + H` | `Cmd + H` |
| **Page Break** | `Ctrl + Enter` | `Cmd + Return` |
| **Format Painter** | `Ctrl + Shift + C` / `V` | `Cmd + Shift + C` / `V` |
